I just finished my Java midterm. Here are some of my thoughts on Java. Compared to C, it encapsulates a lot of things and simplifies many boundary checks and memory management. The downside is that after learning C, I feel less secure, and there are many ready-made methods that can be called directly. This means I can use it just by learning its syntax and function calls, without having read the source code or knowing how the underlying implementation works. That really does boost development efficiency.

As for its object-oriented design, Java is built around this paradigm from top to bottom, offering a new way of thinking about programming. But it feels as though it were built for this one purpose alone. As a result, function names are verbose, and most of them read like path names. Python, on the other hand, balances these aspects well.

Also, I'm only a beginner, and these are just my current views. Besides its object-oriented design, Java also solves the problem of running the same program on different devices. So what do you think?
